# Accessibility checklist (TalkBack)

Automated checks run on every deploy (`e2e/v28.spec.js`): axe on home, result,
history, list, about and the glossary in light and dark mode (no serious or
critical issue), and no sideways scrolling with text at 200 %. The steps below
are what a machine cannot judge. Run them on an Android phone with TalkBack on
before a release that changes screens.

| # | Step | Expected |
|---|------|----------|
| 1 | Open the app, swipe through the home screen | Tabs, "Scanează", "Fotografiază", the paste box and the type selector are each announced with a name |
| 2 | Paste the example and analyse | Focus moves to the result; the verdict is read first, then the summary |
| 3 | Swipe to the score tiles | Each tile is read as one sentence ("Procesare: NOVA 4 din 4, …. Motiv: …") |
| 4 | Double-tap "?" next to NOVA | The glossary opens at NOVA, the title is announced; Back / "Închide" returns to the same place |
| 5 | Expand an additive | Name, risk level and, if any, restrictions outside the EU are read in order |
| 6 | Lista mea → add a person, switch person | The chips announce "selected" for the active person |
| 7 | Toggle a group and an allergen | Each switch announces its name and state |
| 8 | Open the scanner | "Închide" and the torch / type-code buttons are reachable; Back closes the camera |
| 9 | Shopping mode with two products | New cards are announced as they appear |
| 10 | System font size at maximum | Every screen still readable, nothing cut off, no sideways scrolling |
| 11 | Dark mode | All text readable; risk colours still distinguishable by their label, not only by colour |

Report anything that fails with "Raportează o problemă" in the app.
